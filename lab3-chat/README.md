# Лаба 3. Онлайн-чат (C#, .NET 8)

Сервер (консоль) и оконный клиент (WinForms), TCP + JSON, одна строка = одно сообщение.

## Как запустить
```
dotnet build
dotnet run --project Chat.Server            # порт 5000 (или: dotnet run --project Chat.Server 6000)
dotnet run --project Chat.Client            # можно запустить несколько копий
```
В окне входа: адрес сервера (на другом компьютере — его IP в локальной сети), порт, ник.
Если Windows спросит про брандмауэр для сервера — разрешите доступ.

## Как устроен проект
| Класс | Отвечает за |
|---|---|
| `ChatMessage` (Chat.Common) | одно сообщение, JSON туда и обратно |
| `ChatServer` | приём подключений, список клиентов (под `lock`), рассылка |
| `ClientHandler` | одно подключение на сервере, свой поток |
| `HistoryStore` | файл истории |
| `ChatClient` | подключение, отправка, фоновое чтение, события |
| `LoginForm`, `ChatForm` | окна; из потока сети обновляются через `BeginInvoke` |

## Протокол
Каждое сообщение — одна строка JSON в UTF-8, оканчивается `\n`.
Поля: `type`, `nick`, `text`, `to`, `time` (UTC), `users`.

| type | направление | поля | смысл |
|---|---|---|---|
| `login` | клиент → сервер | nick | первая строка после подключения |
| `login_ok` / `login_error` | сервер → клиент | nick / text | результат входа (ошибка — ник занят или некорректен) |
| `text` | оба | text (+ nick, time от сервера) | публичное сообщение |
| `private` | оба | to, text (+ nick, time от сервера) | личное; получают отправитель и адресат |
| `join` / `leave` | сервер → клиенты | nick, time | кто вошёл / вышел |
| `users` | сервер → клиенты | users | актуальный список онлайн |
| `error` | сервер → клиент | text | например, адресат личного сообщения не в сети |

Пример: `{"type":"text","nick":"vasya","text":"привет всем","time":"2026-11-27T11:03:00Z"}`
